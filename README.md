# Tugas Erry Septiadi

Contoh workflow n8n untuk mengambil prakiraan cuaca BMKG dan mengirim rekomendasi perawatan kebun melalui Telegram.

## Import ke n8n

Import `Tugas_Erry_Septiadi.example.json`, lalu ganti placeholder dengan ID spreadsheet, nama atau ID sheet, Telegram chat ID, serta kredensial n8n milik Anda. File `Tugas_Erry_Septiadi.json` adalah salinan lokal dan tidak dilacak Git.
